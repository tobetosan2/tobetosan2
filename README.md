## ⭐ Projetos em destaque

### ☕ Sistema de Gerenciamento de Alunos — Java

Sistema desenvolvido em Java para gerenciamento de cadastros de alunos.

O projeto implementa operações CRUD (Create, Read, Update e Delete), permitindo cadastrar, listar, consultar, atualizar e excluir alunos.

**Conceitos aplicados:**
- Java e Programação Orientada a Objetos (POO)
- Classes, objetos, atributos e métodos
- ArrayList e Scanner
- Estruturas condicionais e de repetição
- Validação de dados
- Git e GitHub

🔗 [Ver projeto no GitHub](https://github.com/tobetosan2/sistema-gerenciamento-alunos)

**Conceitos aplicados:**
- SQL e MySQL
- Power BI e DAX
- Power Query
- Tratamento e organização de dados
- Indicadores e visualização de informações

🔗 [Ver projeto](https://github.com/tobetosan2/dashboard-comercial-powerbi)
